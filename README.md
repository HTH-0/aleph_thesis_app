# 사운드 워크

실제 서울·대구 지도 위에서 소리를 단서로 길을 찾는 3D 길찾기 게임입니다. 거리는 국토교통부 GIS건물통합정보와 OpenStreetMap의 건물 모양과 층수로 세웠습니다.

> 길치이든 아니든 누구나 가볍게 길찾기 게임을 즐기고 싶을 때, 이 앱은 논문에서 쓴 "서로 다른 음색의 고정 소리 랜드마크" 규칙으로 만든 3D 길찾기 게임을 제공하고, 소리가 있을 때와 없을 때의 기록을 논문의 비율 방식으로 비교해 보여 줍니다.

- 논문: 미로형 3D 공간에서 고정 청각 랜드마크의 개수가 길찾기에 미치는 영향 ([thesis.md](thesis.md))

## 논문에서 가져온 것

| 논문 | 게임 |
|---|---|
| 서로 다른 음색의 고정 소리 3개 (2.1) | 지역마다 성격이 다른 장소 소리 3개를 실제 위치에 둡니다 (`js/world.js`의 `pickLandmarks`) |
| 목적지에는 소리를 두지 않음 (2.1) | 목적지는 소리 장소에서 40m 이상 떨어진 곳만 고릅니다 |
| linear 감쇠, 일정 거리 밖 무음, 가까우면 떨림 (2.1) | `js/sounds.js` (논문 `sim/audio.js`와 같은 구조) |
| 안개로 가까운 곳만 보임 (2.1) | 게임에서는 실제 거리를 보여 주려고 약 300m까지 보이게 넓혔습니다 (`js/config.js`의 `FOG_FAR`) |
| 자기 소리 없는 시행 대비 시간비 (2.5, 3.1) | 결과 화면의 시간비와 논문 참가자 5명 비교 |

## 실행 방법

필요한 것: Python 3 또는 Node.js 가운데 하나, 최신 Chrome이나 Edge, 헤드폰.

```
python -m http.server 5173
```

또는

```
npx serve -l 5173 .
```

브라우저에서 `http://localhost:5173`을 엽니다. `index.html`을 더블클릭해서 열면 지도 파일을 읽지 못하므로 꼭 서버로 엽니다.

## 짧은 확인 방법

1. **지역 고르기**: 첫 화면에서 지역(서울: 잠실, 상암 / 대구: 반월당, 서문시장)을 누르면 "이 동네에서 들리는 소리"에 소리 3개가 나옵니다. ▶를 누르면 소리가 납니다. 통과: 지역마다 소리 3개가 보이고 재생됩니다.
2. **두 판 길찾기**: "게임 시작" → 지도 확인 → "기억했어요, 출발" → 화면 클릭. W A S D와 마우스로 금색 기둥까지 걷습니다. 한 판은 소리 없음, 한 판은 소리 있음입니다. 통과: 금색 기둥에 닿으면 다음 판이나 결과로 넘어갑니다. 빨리 확인하려면 주소 끝에 `?test=1`을 붙이고 게임 중 `P`를 누르면 바로 도착합니다.
3. **기록 비교**: 결과 화면에 두 판의 시간, 시간비 문장("소리가 있을 때 1.3배 빨랐어요" 등), 논문 참가자 5명과 "나"의 막대가 나옵니다. 통과: "나" 막대가 논문 5명 막대와 함께 보입니다.

잘못된 입력 확인: `?region=없는지역`으로 열면 첫 지역이 선택됩니다. 게임 중 Esc를 누르면 멈추고 "이번 판 포기하기"를 고를 수 있습니다. 폭 10m 이상인 큰 차도는 보행자 울타리로 막혀 있어서 교차로 앞 횡단보도로만 건널 수 있습니다(신호와 관계없이 건널 수 있고, 차가 멈춰 줍니다). 지도 끝으로 가면 공사 가림막에 막히고 "이 길은 공사 중이라 지나갈 수 없습니다" 문구가 나옵니다. 소리 파일이 없으면 합성음으로 대신 재생합니다.

## 데이터와 출처

- 횡단보도: 공공데이터의 실제 횡단보도 도형을 씁니다. 서울은 [서울시 교통안전시설물 횡단보도 정보](https://data.seoul.go.kr/dataList/OA-15554/S/1/datasetView.do)(서울특별시, 공공누리 제1유형, 2026-10-01 갱신), 대구는 [대구광역시_횡단보도](https://www.data.go.kr/data/15029067/fileData.do)(대구광역시, 공공데이터포털, 2023-08-16 파일)입니다. 원본 파일은 저장소에 넣지 않고 `참고자료/공공데이터/`에 두고 지도를 만듭니다. 실제 횡단보도가 없는 큰길 때문에 지도가 끊기는 곳에만 규칙 횡단보도(교차로·중간)를 더합니다.
  - 교차검증(2026-10-16): 규칙으로 정했던 큰길 교차로 가운데 실제 횡단보도가 35m 안에 있는 비율은 잠실 82%, 서문시장 81%, 상암 78%, 반월당 57%였습니다. 반월당은 사거리를 지하상가로 건너는 구조라서 낮게 나왔습니다. 규칙 횡단보도는 반월당 교차로 3곳, 서문시장 교차로 1곳에만 남았습니다.
- 건물: [GIS건물통합정보](https://www.vworld.kr/dtmk/dtmk_ntads_s002.do?svcCde=NA&dsId=18)(국토교통부, 브이월드, 2026-10-09 기준, 저작자표시 CC BY)의 건물 도형과 지상층수를 OSM 건물과 합칩니다.
  - 같은 건물(서로 절반 넘게 겹침)이면 모양은 공공데이터를 쓰고, 층수는 건축물대장(공공데이터) → OSM → 용도·면적 추정 순서로 씁니다.
  - 한 건물의 모양과 높이는 한 출처에서만 가져옵니다. 지도 파일에서 공공데이터 건물은 `g: 1`로 표시해 OSM 건물과 따로 둡니다.
  - 공공 건물이 OSM 차도 중심선을 4m 넘게 덮으면(두 데이터의 골목 위치가 어긋났거나 길 위 아케이드) 길이 막히지 않도록 그 건물은 쓰지 않습니다.
  - 지역별 건물 수와 층수가 3층 넘게 다른 건물 수는 `data/<지역>.json`의 `sources.buildingCounts`에 있습니다.
  - 겉모습도 공공데이터에서 고릅니다. 구조(목구조 저층은 기와 우진각 지붕 주택, 벽돌은 붉은 벽돌, 블록·석조는 회색 블록, 저층 철골은 골함석 패널), 사용승인 연도(오래될수록 바랜 색), 높이(층수와 맞으면 실제 높이 m), 아파트 동 이름과 단지 이름(판상형 아파트 옆벽에 "101동"처럼 씀)입니다.
  - 파일은 브이월드에 로그인해서 받습니다(서울특별시, 대구광역시 SHP). 받은 zip을 `참고자료/공공데이터/vworld_building/seoul/`, `.../daegu/`에 풉니다.
- 차도 폭: OSM `width` 태그가 없는 차도는 공공 횡단보도 도형이 그 차도를 가로지르는 길이로 폭을 다시 잽니다. 같은 이름의 길 조각에도 그 값을 씁니다. 큰 차도(10m 이상)인지 아닌지는 바꾸지 않습니다.
- 보도 폭(서울): [서울시 보도 통계자료](https://data.seoul.go.kr/dataList/OA-22240/F/1/datasetView.do)(서울특별시, 공공누리 제1유형, 2025-12-31 기준)의 노선별 보도 폭을 OSM 도로 이름과 맞춰 씁니다. 지역이 속한 자치구 구간을 먼저 봅니다. 대구와 이름이 맞지 않는 길은 큰길 4m, 그 밖의 길 2m로 둡니다. 건물과 보도 사이에 남는 4m 이하 틈은 가게 앞 공간으로 보고 걸을 수 있게 합니다.
- 지도: © OpenStreetMap contributors, ODbL 1.0. `tools/build_maps.mjs`로 받아 `data/*.json`(이동 판정용 2m 격자, 장소 위치, 화면에 그릴 건물·도로·녹지·나무)으로 저장했습니다. 층수 기록이 없는 건물은 용도와 바닥 면적으로 높이를 추정하고, 건물이 없는 넓은 빈 땅에는 저층 건물을 채워 그립니다. 지도 생성 입력(OSM 원본, 지역 범위로 잘라 낸 건물·횡단보도·보도 폭)은 [tools/source/](tools/source/README.md)에 담겨 있어서, 원본 없이도 `node tools/build_maps.mjs`로 같은 지도를 다시 만들 수 있습니다. OSM을 새로 받으려면 `--fresh`를 붙입니다.
- 공공데이터 원본 받기(입력을 다시 잘라 낼 때만): `node tools/fetch_public.mjs`가 횡단보도(서울·대구)와 서울 보도 통계를 `참고자료/공공데이터/`에 받습니다(로그인 필요 없음). 건물 파일만 브이월드에서 직접 받습니다. 그다음 `node tools/build_maps.mjs --refresh-sources`를 실행합니다.
- 소리: Pixabay Content License. 파일 목록과 주소는 [sounds/README.txt](sounds/README.txt)에 있습니다.
- 개인정보: 앱은 기록을 서버로 보내지 않습니다. 음량 설정만 브라우저에 저장합니다.

## 폴더 구조

```
index.html        화면
css/app.css       화면 스타일 (industry.css 위에 얹음)
js/config.js      설정값, 소리 종류, 논문 수치
js/world.js       지도 읽기, 소리 장소와 출발점·목적지 고르기
js/sounds.js      3D 소리 재생
js/scenery.js     3D 거리 풍경 (건물, 도로, 차선, 가로수, 하늘과 그림자)
js/traffic.js     행인과 차량 (신호등을 따르고, 소리는 내지 않음)
js/game.js        3D 길찾기 한 판
js/main.js        화면 흐름과 결과
data/             지역별 지도 (OpenStreetMap과 공공데이터로 만든 파일)
sounds/           소리 파일
tools/            지도 데이터 생성 (build_maps.mjs), 공공데이터 받기 (fetch_public.mjs), Shapefile 읽기 (shapefile.mjs)
tools/check/      검증 스크립트 (사용법은 tools/check/README.md)
```
